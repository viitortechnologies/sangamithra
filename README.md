# Aorg - Freelancer for Business Website

A modern, responsive multi-page website for Aorg, a professional website service provider and digital marketing company.

## 🌟 Features

- **Fully Responsive Design** - Works perfectly on all devices (desktop, tablet, mobile)
- **Modern UI/UX** - Clean, professional design with smooth animations
- **Multi-page Structure** - Home, About, and Contact pages
- **Interactive Elements** - Mobile navigation, smooth scrolling, form validation
- **Performance Optimized** - Fast loading with optimized images and code
- **SEO Friendly** - Proper meta tags and semantic HTML structure

sangamithra/

## 🔧 Customization

### Colors
Edit the CSS variables in `styles.css` to change the color scheme:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1d4ed8;
    --accent-color: #667eea;
}
```

### Content
- Update business information in the HTML files
- Replace images with your own (maintain aspect ratios)
- Modify contact details and social media links

### Styling
- Adjust fonts, colors, and spacing in `styles.css`
- Modify animations and transitions
- Customize responsive breakpoints
